# Changelog

All notable changes to InstaScope will be documented in this file.

## 1.0.0 - 2026-07-18

- Migrated the app to strict TypeScript.
- Added resilient Instagram export parsing for followers, following, paginated files, and empty valid exports.
- Added ZIP archive and multi-file import.
- Added accessible import status, warnings, errors, statistics, result tabs, search, sorting, pagination, copy, CSV export, reset, and theme controls.
- Added PWA app-shell caching and local application icons.
- Added Vitest, React Testing Library, jest-axe, and Playwright coverage.
- Replaced `gh-pages` deployment with official GitHub Actions Pages workflows.
- Added project documentation, security policy, contributing guide, MIT license, and agent instructions.
